POST /v1/prediction/model/{model_code}

Operation ID: PredictV1.

Authentication: bearer token (BearerTokenAuth).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | model_code | path | string | Yes | The model's code: open the model, Settings tab, ID section. |

Request body

application/json

Property Type Required Description
data object Yes
data.predict_values array of array of object or object Yes Either an array of prediction rows (each row an array of alias/selectedValue objects, Binary/Multiclass Classification and Regression models), or a single timeseries object (startDate/endDate/sequenceID[/daysData], Timeseries models).

Responses

200: Prediction results. Timeseries models answer {data: [TimeseriesPoint...]} instead

application/json

Property Type Required Description
data object No Classification/regression prediction results.
data.columns array of string No Column names associated with each prediction row.
data.data array of object No
data.data[].Label string No Predicted label (classification models).
429: Rate limit exceeded (tenant 10/min, global 200/min)

application/json
