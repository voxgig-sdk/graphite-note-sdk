Set up the client

This setup fragment reads credentials from the environment. Use the API operation reference to supply input for each call.

local sdk = require("graphite-note_sdk")
local client = sdk.new({apikey = os.getenv("GRAPHITE_NOTE_APIKEY")})

  "base": "https://app.graphite-note.com/api",
